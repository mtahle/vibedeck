# Project control

Last reconciled: YYYY-MM-DD

This is the canonical register for approved scope, decisions, requirements,
priorities, QA, security, privacy, operations, and delivery status.

## Governance

### Source precedence

1. Latest explicit owner decision.
2. This canonical project-control document.
3. Enforced legal, privacy, security, and platform constraints.
4. Accepted findings and their acceptance criteria.
5. Executable evidence in tests and implementation.
6. Repository instructions.
7. Status history and Git history as historical evidence.

### Priority model

- **P0:** release blocker or material safety, security, privacy, data, financial,
  authentication, or production risk.
- **P1:** required before broad release.
- **P2:** planned improvement.
- **P3:** candidate or research.

### Definition of done

- Acceptance criteria are met.
- Relevant risks and trust boundaries are reviewed.
- Proportionate automated and manual checks pass.
- Documentation and operational instructions are current.
- `STATUS.md` records the change and remaining risk.
